# 楼层分户到整层合成

1. 在「楼层分区 → 环境搭建」编辑外轮廓、结构、交通核与分户要求。
2. 「显示 → 图层显示与透明度」可开启粉色分户推演，默认关闭。粉色表示当前参数的自动推演，黄色表示户门；这些形状不是训练结果，也不是可编辑的结构约束。隐藏图层不会修改建筑输入。
3. 在「布局预览」选择第一阶段结果。也可以明确生成一个未训练推演；页面会显示方案来源。
4. 点击「采用此方案，创建逐户训练清单」。每户生成独立配置，保留原楼层坐标、整层轮廓和扣除隔墙厚度后的户内净边界。
5. 在「整体合成」选择一户，进入「环境搭建 → 智能体与关系」设置房间和面积，保存后训练。当前工作台一次运行一个任务；不代表算法只能串行。
6. 训练完成后回到「整体合成」，选择本户的有效记录，再处理下一户。修改房间需求或边界后，旧结果会被标为过期。
7. 全部户型通过几何、已声明关系、覆盖与重叠检查后，下载整层 PNG、SVG 和坐标。未完成时仅显示过程草图。

交接文件为 `exports/floor_plan.json`，逐户清单位于 `results2/floor_workflows/<方案编号>/workflow.json`。再次采用同一方案不会覆盖已编辑的房间配置。不同方案的训练结果不能混用。

合成按真实坐标重绘，不拼接截图。目前输出房间功能分区，不包含室内门窗施工详图；几何验收也不等于规范审查。
