# A1：原图复核后的对称建筑环境

以原图通道1500毫米为参照，主体照片估算约28.6×9.9米，配置取28×10米；交通核上部宽16米，总高15米。这是模数化设计抽象，保留左右对称，不是实测复原。

## 几何

- 对称轴x=14米，主轮廓坐标取整米，交通核前退台保留0.5米。
- 18根柱统一600×800毫米，包含交通核旁两根；柱始终作为独立固定结构。
- 柱轴x=[0.3,5,10,18,23,27.7]米，y=[0.4,5,9.6]米。
- 外围柱的外侧面贴合建筑轮廓；半柱宽引起的柱心小数必须保留，全部尺寸均可表示为整数毫米。
- `config.yaml` 是唯一几何来源；`build_a1.py` 只验收并更新预览，不覆盖配置。

## 走道与隔墙

走道、户门和分户边界自动联合调整。A1门间距为1.2米，指不同门洞线段之间的最短直线距离；2.4米保留作参数对照。两者都是设计参数，不是法规结论。

走道净宽1.5米，门前净空1.2×1.2米，门宽0.9米。门厅深度按0.25米逐档尝试，考虑核旁柱的避让；连通的旧走道条带允许分给不同户型。

隔墙默认厚0.2米，不属于原有结构约束。分区多边形沿墙中线定义；贴柱边时，墙中线偏移半墙厚，使隔墙完成面与柱面重合。隔墙两侧扣除墙厚后才计算净面积、通行净宽和门前净空。

下一阶段导出的 `ExistingBuilding.boundary` 是户内完成面边界，门位置也是墙内表面位置；墙中线仅保存在结果元数据中。原有柱洞继续保留，房间智能体不能进入隔墙厚度范围。

## 评价与显示

逐户检查面积、外墙长度、采光进深代理、连通性和有效宽度；这些采光指标不等于真实照度模拟。等面积目标在1%以内的偏差不额外扣分，避免为追求微小均分差异扩大门厅；可用 `FloorPartition.quality.area_balance_deadband` 调整，设0恢复严格面积偏差评分。

灰色为隔墙，深色为原有柱墙，浅底黑色斜线为交通核；蓝色为公共交通，绿色短线为户门。

当前预览和逐户指标分别见 `partition_preview.png`、`validation.json`。该方案来自有限搜索，不代表走道面积的全局最小值。建筑环境的对称性不强制所有搜索结果完全对称。
