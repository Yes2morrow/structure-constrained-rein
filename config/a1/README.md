# A1 北角上润中心 14F 建筑环境

配置文件为 `config.yaml`，在工作台配置编号列表中选择 `a1`。程序将编号统一转为小写；配置内部的 `ConfigID` 为 `A1`。原 `retrofit` 配置及当前选择保持不变。

## 比例和坐标

- 参考用户指定的图一中央通道 **1500 mm = 1.500 m**，采用两侧内边线约 x=512、550 的38像素间距，比例为 **0.039473684 m/px**。
- 图像尺寸1000×750；原点设在图上整层左下角约(170,559)，x向右、y向上，长度单位m、面积单位m²。坐标轴依图纸方向，不代表地理正北。
- 同一比例用于水平及竖直方向，轮廓作正交化处理。照片存在轻微倾斜，未作透视校正。柱宽、柱位、端部圆角及细部墙线均为影像估算，不能视为实测尺寸。图面印刷比例不参与标定。

## 环境内容

按**整层**建模，橙色Unit A仅为原图中的一个单元。

| 内容 | 配置方式 |
| --- | --- |
| 整层外轮廓 | 14顶点阶梯多边形，约28.58×14.96 m，外包尺寸包括上方交通核 |
| 图二蓝色区域 | 5个相接的 `traffic_core` 矩形，合并为一个连通区域，包含电梯、楼梯、大堂及两侧服务空间 |
| 中央纵向通道 | `retained_circulation`，净宽1.500 m、估算长度7.026 m |
| 核外黑色柱位 | 16个 `column`；核内构件由交通核整体覆盖 |
| 大堂—通道连接 | `door_positions` 是通道上端1.5 m连接截面，不是室外入口 |

估算面积：整层轮廓358.87 m²，交通核80.28 m²，保留通道10.54 m²，扣除交通核、通道和柱后的可用区域258.87 m²。面积按配置几何计算，包含正交化及圆角简化的影响。原A/B/C/D单元隔墙缺乏结构属性证据，未当作承重墙锁定。

## 使用范围

本配置只建立既有建筑环境，未另行编造室内房间任务，所以 `TargetSpaces` 与 `FunctionalRelations` 为空，种子训练与自动分区关闭。沿用工作台支持的 `room_training` 阶段作为环境编辑入口，**尚不是可直接开始室内训练的任务**；开始训练前需要设置目标空间。

`FloorPartition.residential` 的四户均分只是可编辑占位参数（参考原图四个单元），不是已确定的改造方案。当前分区算法使用交通核外包矩形生成横向走道，不能准确复现这个阶梯核和中央纵向通道；切到“楼层分区”会自动启用该算法，应先适配算法再训练。此次没有修改算法代码。

## 校验与复现

`validation.json` 记录真实项目几何编译器的检查结果：边界有效、所有固定区域在界内、交通核连通、通道净宽1.5 m、核与通道无面积重叠且相接长度1.5 m。

`A1_environment.png` / `A1_environment.svg` 为配置几何预览。原图像素取点、换算比例和建模假设都保存在YAML的 `SurveyReference` 中。
