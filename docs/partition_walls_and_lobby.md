# 分户墙厚、对齐标准和集中门厅

## 本次修改

分户线表示墙中线。`FloorPartition.residential.wall_thickness` 默认 0.2 米，两侧各占 0.1 米；环境设置页可以修改。设置为 0 可作无墙厚对照。

内部计算保留完整的中线分区，再计算墙体和净使用区域。户型面积、走道净宽、采光机会和门前净空使用扣墙后的几何。交通核、原有墙柱不重复扣除。门槛面积单列，净使用面积不计门槛。四部分之和必须等于建筑内面积：原有固定结构、户型与走道净面积、新隔墙实体、门槛。

导出的户内配置采用墙内表面边界，入口也平移到内表面；同时保留原分区中线边界和门洞中线坐标。结果图中蓝色为公共交通、黄色为户门、灰色为新隔墙，结构更深，交通核使用黑色斜线。环境编辑画布中的可选推演图层使用粉色，明确区别于结构输入和训练结果。

## 对齐不只允许中线

允许中线对结构中轴，也允许新墙某一面与柱或原有墙的边缘重合。后者先计入半墙厚，不能直接把分户中线当成完成墙面。

候选参考包括中轴，以及结构低坐标侧、高坐标侧的内贴与外贴。竖墙的低/高坐标侧就是左/右侧，横墙则是下/上侧。以柱宽 0.6 米、墙厚 0.2 米为例，内贴左侧时，新墙中线相对柱中轴偏移 -0.2 米，而不是 -0.3 米。

评价取同一种对齐规则所覆盖的共边长度，混用中线、左贴、右贴会降低该项得分；已有转角和短边惩罚继续抑制折转。中线和贴边采用同等权重，由搜索和策略选择。这是软偏好，不是强制每面墙贴柱，也不保证有限训练后所有墙都完全一致。

验收报告区分三个指标：结构参考线覆盖比例、统一规则覆盖全部共边的比例、已识别结构对齐段内部的一致比例。自由空间内的补充模数线不冒充柱轴线。

## 为什么原来难以得到集中门厅

原来的起点主要来自交通核外扩条带；局部动作逐段释放走道，很容易先让外侧户型失去入口，导致候选被拒绝。

现在根据真实核入口边及两侧退台生成矩形门厅候选，不写死 A1 坐标。一次修改可同时替换走道、把释放的整段走道分配给邻户，并重选受影响的门位。初始化时还尝试在远离门厅的结构线处重新平衡户型面积。普通局部修改与门厅修改共用独立验收。

动态动作仍受修改面积、图单元数、候选数和时间限制；未变化的走道不占修改范围。范围外户型与户门保持不动。初始化中的面积重分配不属于动态动作的局部预算。

集中门厅并不必然面积更小。用 `scripts/compare_partition_lobbies.py` 保持 A1 的柱网、墙厚、净宽等设置不变，仅对照户门间距，得到：

| 最小门间距 | 已验收的矩形门厅净面积 | 参数用途 |
|---|---:|---|
| 2.4 米 | 30.62 平方米 | A1 当前设置 |
| 1.2 米 | 18.92 平方米 | 单独的参数对照，不覆盖 A1 |

这些是本次有限候选中的可行结果，不是面积最小值证明。更大门厅为侧面门和正面门提供了所需间距。图3所示形式可以生成，但示意图本身不能证明尺寸满足当前参数。
