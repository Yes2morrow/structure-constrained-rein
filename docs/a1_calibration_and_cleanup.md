# A1校对、走道改进与项目整理（2026-09-18）

## 原因与修正

原配置将外围柱整体放在外墙以内，且跳过了交通核旁两个柱位。现在按原图1500毫米参照，将主体由30×10米校正为28×10米，核上部由18米改为16米；18根柱统一截面、左右对称，外围柱外侧面贴建筑轮廓。原图的局部不对称及楼梯圆角仍作为设计抽象处理。

原门厅偏大有多项原因：所有户门之间的2.4米距离要求、深度候选过稀、直墙接触边被切成短段后无法识别完整门洞，以及评分过度追求近乎完全均分。现保留门间距设置，A1改用1.2米；补足中间深度、合并共线门边，并让1%以内的面积误差不额外扣分。

新柱网暴露出初始化的另一限制：先有可开门的条带方案，才能尝试集中门厅。现在允许尚未满足门位的临时起点进入门厅重划分，但只有完整验收通过的方案才能输出。释放的连通条带可分配给两侧户型；入口转折沿柱轴或柱跨中线重新组织，再平衡户型面积。

原有柱造成的轮廓凹口不再当作新增隔墙的无意义折角；采光面积要求在扣墙后检查，避免按毛面积提前误删可行方案。小型、三面被原有结构围住的死角计入公共面积，单独报告，不能用它替代通道或门前净空。

## 隔墙、结构与下一阶段

分户墙是可调整的非承重隔墙，不加入固定结构或结构参考轴。结构参考来自原有柱、剪力墙和承重墙，并修正了 `load_bearing_wall` 类型的识别。

贴边的对象是隔墙完成面，不是墙中线。以柱右边x=10.3米、墙厚0.2米为例，向柱内侧贴齐时墙中线为x=10.2米，完成面为x=10.3米；墙厚改为0.4米，中线改为x=10.1米。几何测试同时覆盖这两种墙厚。

导出只把净边界交给户内训练，中心线边界另存元数据；门洞平移到户内完成面，结构孔洞保留。测试实际创建房间智能体环境，验证它拒绝进入半墙厚区域。

## 项目整理

- 删除无调用方的旧网格生长与旧门位求解代码（`growth.py`、`doors.py`）；结果和户门数据模型统一放入 `contracts.py`。
- 删除旧走道矩形辅助函数；当前入口、普通搜索和PPO共用精确几何验收。
- `scoring.py` 统一起点、搜索和训练评分，`rendering.py` 独立承担绘图。
- `common/plan_styles.py` 统一隔墙灰、结构深色和交通核斜线；界面对象身份与编辑坐标不受配色影响。
- `core` 和环境入口延迟加载重型依赖；纯分户几何导入不再自动加载Torch或Gym。
- A1配置只在YAML中定义；生成预览不重置用户参数。
- 已入Git标签的历史A1副本从当前配置目录移除；训练结果、模型和其他用户配置保留。
- 对照实验写入新的结果目录；候选预算内未找到方案时明确记录，不声称全局无解。

## 验证与边界

全项目157项回归测试，154项通过、3项按条件跳过，日志 `runtime/a1_webui_full_tests.log`。覆盖外围柱、漏柱、对称性、实际墙面贴齐、共线门边、净面积守恒、下一阶段边界、画布对象往返、前端参数保存与净边界下载及PPO更新。

另增加并通过1项并发预览测试：连续刷新时共用已在计算的预览，避免多个网页线程重复搜索；日志 `runtime/preview_concurrency_test.log`。

A1预览与独立验收在 `config/a1/`，短训练在 `results2/floor_partition/a1_recalibrated_training/`。短训练只验证功能链，不代表收敛或跨建筑泛化。

当前仍是有限候选和局部搜索，不证明最小走道或最优户型。不同几何与门间距下未找到候选，应查看约束和搜索预算，不应自动降低净宽或丢弃面积。

本次最终预览走道净面积23.61㎡，各户面积偏差约1.20%，综合评分11.116。早先扩大搜索的对照方案走道为19.91㎡，但各户面积偏差约2.65%、综合评分10.990，因此没有为了缩小走道强行替换默认结果。对照保存在 `results2/floor_partition/a1_lobby_comparison_20260918_023021/`。门间距2.4m的对照在当前候选预算内未找到方案，不等于全局无解。

网页实测另发现局部重组产生约1e-14米的共边误差，会使精确交线漏掉墙段。墙体构建现在先把临时副本统一到1e-8米精度，固定结构数据不变；新增测试覆盖该误差及真实A1页面的净边界下载。

## WebUI入口

左侧选择 `a1 → 楼层分区（分户型）`。

- 「环境搭建」：设置墙厚、走道净宽、门宽、门间距；展开「门前通行与净空」设置门前宽度、深度和门内深度。
- 「分户质量约束」：设置面积误差上限、面积均衡免罚范围、最小宽度、最多转角、窄小区域比例、结构参考线比例和采光机会要求。对齐方式由搜索与训练选择，墙面贴边按半墙厚反推中线，不强制所有墙沿柱轴。
- 「分户预览搜索预算」：开关紧凑门厅候选，设置预览修改次数和初始候选预算。预览0次只生成初始方案；该数值不替代训练步数。
- 「导出户内训练净边界」：下载每户配置ZIP及验收JSON；户内边界扣除墙厚、门位在户内完成面，仍需自行配置房间需求。
- 「参数配置」：设置每轮修改次数、学习率、随机种子、局部最大面积、单元数、候选数与时间预算。隐藏此阶段不生效的户内奖励滑块，避免误改。

环境参数修改后点击「保存既有建筑环境」；训练参数点击「保存参数配置」。参数不满足约束时显示原因，不自动放宽要求。
