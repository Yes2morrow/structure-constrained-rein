# A1 v2：对称模数化环境与结构约束分户

工作台选择配置编号 `a1`，进入“楼层分区”。`config.yaml` 已启用自动走道和分户策略训练。照片估算旧版保存在 `image_estimate_v1/`，仅供历史对照，旧脚本不用于重建当前配置。

## 几何设置

- 主体矩形30×10 m；连同上方交通核，总外包尺寸30×15 m。关于x=15 m左右对称。
- 柱截面统一0.6×0.8 m（600×800 mm）。
- 柱轴x=[1,6,11,19,24,29] m，跨距=[5,5,8,5,5] m；y=[1,5,9] m，跨距4 m。
- 核外16根柱；上排位于核内的两个位置不重复建模。
- 核由四个相接矩形组成。主轮廓、核边及柱中心使用整米坐标；1.5 m走道、0.9 m门宽等保留实用尺度。
- 这是基于照片的设计抽象，不再表示照片逐像素估算，更不是实测图。

## 自动走道和户门

上一版纵向走道是手动设置的，现在已删除全部 `retained_circulation` 对象。

算法对**实际交通核轮廓**作1.5 m正交外偏移，裁切至建筑边界内并避开固定结构；按开口方向，从短到长尝试走道范围。每个方案必须连通、接到核开口、通过净宽检查，并能安排各户的门前净空与门间距。走道面积进入优化评价，不要求复现原图。

A1当前结果为贴核折线走道，面积24.00 m²；完整外偏移包络为31.50 m²。户门净宽0.9 m，门前预留1.2×1.2 m，门内深度0.9 m，门段之间最小净距2.4 m。这些是项目可调参数，不是法规合规结论。

## 分户规则与采光

分户采用结构参考线上的直线递归切分。参考线来自柱轴、柱边、交通核/墙边、柱跨中线及整层外包中线；允许沿核轮廓形成凹凸，不强制矩形。禁止离散小岛、户间重叠、遗漏面积、占用固定结构、无门接入以及不符合参考线的户间分界。

每户有效采光外墙长度必须满足：

`L >= max(3 m, 0.12 m/m² × 户型净面积)`

有效外墙仅计算建筑真实外轮廓上、未被交通核或实心构件占据的边；户间墙、交通核界面和走道边均不计入。当前默认假设其余外墙可以开窗。此指标只是采光机会的几何代理，未输入窗墙比、邻楼遮挡、朝向或玻璃参数，不能保证实际日照/照度达标。

质量参数位于 `FloorPartition.quality`；界面提供外墙长度比例、每户最小外墙长度、面积容差和最小有效宽度。A1面积容差为25%，最小有效宽度1.5 m、外边界转角上限24。

| 01 | 77.12 | 26.00 | 9.25 |
| 02 | 54.04 | 7.00 | 6.48 |

## RL的实际范围

旧 `train_floor_partition.py` 只有规则计算，没有策略更新。现在实现了**单步上下文老虎机REINFORCE**：

1. 有界beam search生成结构直线切分候选，逐个进行独立几何验收。
2. 每次动作选择一个可行的整层候选；状态特征包含面积误差、转角数、走道面积、外墙充足率及结构对齐。
3. 策略梯度实际更新参数，包含熵正则；保存模型、优化器、特征归一化、训练日志。
4. 导出保留经过验收的最佳搜索方案，避免训练随机探索降低交付结果质量。

奖励为 `10 - 8×平均面积误差 - 0.1×平均额外转角 + 0.4×min(最低外墙充足率,2) - 0.035×走道面积`。硬约束失败的方案不能成为动作。不是MAPPO、不是多步逐边编辑，也不宣称跨建筑泛化或全局最优；候选搜索以递归直线切分为边界，不能枚举所有正交平面拓扑。未找到方案会明确报告，不会放宽约束或丢弃小分量。

实测128轮，24个可行候选，策略参数确有更新；候选分布期望奖励约7.946→8.050。导出方案来自最佳已验收候选，不能把它的几何质量提升全部归因于RL。

## 文件与运行

- `A1_environment.png/svg`：模数化建筑环境，黄色为自动走道。
- `partition_preview.png/svg`：分户方案。
- `validation.json`：逐户面积、外墙长度和独立验收结果。
- 项目 `results2/floor_partition/A1_modular_verified/`：128轮训练、模型、分户预览、验证及各户导出配置。

在项目根目录：

```powershell
& '../.venv312/Scripts/python.exe' config/a1/build_a1.py
& '../.venv312/Scripts/python.exe' scripts/train_floor_partition.py --config-id a1 --episodes 128
& '../.venv312/Scripts/python.exe' scripts/train_floor_partition.py --config-id a1 --no-rl
```

导出户型保留柱洞和固定构件，切回户内训练阶段；房间功能任务须随后设置，不复用整层或旧住宅的错误房间参数。重建脚本会恢复本版A1参数，手动调整后请先另存配置。
