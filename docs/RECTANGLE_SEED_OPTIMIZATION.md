# 原矩形基础上的图种子加速优化

页面将矩形直接优化和图种子加速表述为同一改造任务的两种求解方式。retrofit 配置默认启用加速；取消勾选可运行原十三动作矩形策略作对照。

共同输入包括原空间矩形、初始功能空间矩形、建筑边界、固定结构、目标面积、形态范围、功能关系与 RewardWeights。未显式设置种子时采用初始矩形中心。复用与改造参照优先取同 ID 的 original_spaces，缺失时取 initial_rect；种子移动不会改变参照。

加速训练采用五动作种子位置决策和栅格快速估算，继承面积、形态、邻接、分离、结构顺应、复用、改造干预、非法动作、团队协调权重。形态加入规整度与碎片惩罚，邻接保留距离接近的过程反馈。参照矩形与网格的交集只在初始化计算，训练步内不精确解码。

每 250 轮、结束或请求停止时约束生长成图并验证面积、轮廓、结构避让和实际共边；精确报告增加原空间复用率及改造率。复用为交并比；改造率沿用基础方法的对称差面积除以两者面积最大值，其数值可超过 1。代理指标不能证明最终邻接，connected/via_circulation 仍需门或通路证据。

两种策略共享问题与目标，但不是相同神经网络：十三动作矩形权重不能直接加载到五动作策略。新检查点记录 retrofit_v1 奖励版本，旧固定奖励的种子检查点也不能直接续训；旧结果仍可读取。加速训练按最大步数结束回合，未把估算达标当作精确成功。尺度动作、随机扰动和矩形提前终止参数在加速时禁用。

本次完成的是共同优化目标与入口整合；没有通过长程训练证明所有案例的最终成图或邻接优于原方法。
