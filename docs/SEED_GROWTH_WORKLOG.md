## 1. 已确定的设计约束

1. 图节点是房间的生长种子，不强制等于房间最终质心。智能体必须能够移动种子；首版仅移动种子，不把方向权重或横纵偏好预先定为学习动作。
2. 训练期间只使用快速、粗略但可靠的代理评价，估计种子位置可能生成的面积、形态、关系和冲突。不得每个 step / episode 运行精确生长。
3. 精确生长在累计完成 250、500、750……轮，以及正常训练结束、用户请求停止时执行。同一个最终轮次只生成一次。模型检查点保存频率独立于此频率。
4. 精确生长输入是一个完整种子快照，多个房间联合分配空间；有冲突时统一仲裁，可局部退让，不按固定房间顺序抢占。
5. 墙柱厚度在最初构建环境时就形成固定多边形。代理地图与精确几何使用同一份不可侵入区域；不能把墙简化成无厚度线参与碰撞。
6. 默认遇柱/墙时整段扩展边停止。仅在长边多障碍条件或房间允许局部凹凸时，才评估分段生长；不能一遇柱就自动生成凹口。
7. 厨房、卫生间、客厅可配置允许有限凹凸，但不是无条件放宽。用相对形状损失、局部最小宽度和凹口深度衡量，不单凭绝对面积或房间名称。
8. 斜墙允许产生直线斜边；“直线边缘”不等于所有边必须水平/竖直。接触的是有厚度墙体的可达外表面。
9. 图关系区分：共边邻接、可开门连通、经交通空间连通、分离。靠近的节点或隔着不可开洞墙体的房间，不自动视为可连通。
10. 成图必须验证面积、形态、种子归属、连续性、结构侵入和房间重叠。无法满足时输出缺口与原因，不把失败图标记为有效成图。

## 2. 墙柱接触与局部形状规则

### 默认整边停止

- 用可移动的直线边段组成边界；每次求首次碰撞事件，而非固定微步盲目扩展。
- 短边或单个局部障碍：先尝试整边停止，把剩余面积需求交给其他边。
- 多障碍长边：先把接触投影合并成阻挡区间，再产生少量候选分段；限制段长、凹口数、凹口深度与新增周长。
- 允许凹凸的房间也必须整体规整；先比较整边停止与分段结果，只有面积收益值得形态代价时才分段。
- 柱子不能因边界绕行而被悄悄包进房间净面积。首版不自动产生带洞房间；若为结构柱预留洞，需以后显式配置和净面积核算。

### 斜墙 A/B 候选（实现时必须有几何案例检查）

用户 A：扩展边先接触墙体的一端停止，另一端继续，形成贴合可达墙面的斜边。按有限墙面计算；若需要沿墙面支撑线外延，只有延伸段全程在自由空间、满足轮廓约束时才可接受，不能穿墙或越界。

用户 B：若另一端越过墙端点投影范围，先按扩展轴对齐墙体端部的相应 X/Y；在另一坐标的对应投影处拆分边段；再让新端点延伸至可达墙体外轮廓端点，形成分段折边。

- 坐标中的“墙尽头”必须从墙体实际多边形外边界提取；墙线端点不能替代厚度轮廓角点。
- 把东/西/南/北扩展统一映射到局部切向/法向坐标，再实现 A/B，避免四份逻辑的方向错误。
- A/B 是候选构形，不预定 A 永远优先。整边停止、A、B 共同接受无侵入、无自交、面积、最小宽度与规整度筛选。
- 不能仅对扩展多边形做 difference 后直接接受碎片；必须保持种子所在的单一连通房间。
- 待验证而非用户待批准事项：用四方向、墙线反向、左右不等厚、另一端超出有限墙长的案例固定 A/B 几何语义。

## 3. 两级评价与图表示

### 训练代理（CP2）

- 环境初始化一次生成保守障碍占用与可达性地图；薄墙不能在粗网格中消失。对过窄通道可标为不确定，不能假报可通过。
- 图节点保留功能、目标面积、面积范围、比例范围、形状规则和种子坐标；图边保留关系类别及阈值。
- 首版采用固定关系图和普通 MAPPO 观测，暂不引入 GNN，不为速度目标扩大网络改动。
- 用障碍感知的距离/可达容量与有限轮次空间竞争估计布局；禁止仅使用欧氏距离跨墙推断邻接。
- 每个 step 仅更新变化种子的代理量；缓存固定障碍、连通分区与相同种子状态。代理输出明确标记 estimated。
- 分离代理误差和非法种子惩罚。种子不能落在结构内、边界外或与其他种子重合。

### 精确解码（CP3 / CP4）

- 从全部种子同时开始，以面积缺额、可用方向稀缺性、邻接边需求提出生长候选。
- 冲突区域统一仲裁，采用确定性的排序/仲裁规则并报告无法分配区域；结果必须可复现。
- 先实现纯正交、整边停止；通过后增加受控分段和斜墙 A/B。支持阶段不得混淆。
- 保留未分配空间和交通需求，不要求房间面积占满所有自由面积。

### 代理可靠性校准

- 每次 250 轮精确结果与同快照代理结果对比：面积误差、邻接误判、连通误判、形状偏差。
- 精确结果不伪装为之前每步已知的奖励；首版用于校准报告、选择候选与后续调整代理。
- 精确失败时不能继续输出成功状态。保存种子、失败原因及上一个有效成图，并清晰区分。
- 在固定测试集达到约定误差/误判门槛前，新模式维持实验入口，不替换当前训练默认。

## 4. 规整度评价（不是建筑规范合规证明）

硬条件：有效单连通多边形、包含种子、不越界、不侵入固定结构、不与其他房间发生面积重叠；面积上限与明确最小宽度要求不得用奖励抵消。

软正则建议：面积误差 + 包围盒比例偏差 + 矩形度损失 + 归一化额外周长 + 凹角数 + 相对凹口深度。矩形度可允许适度下降，但不能用它单独判断房间是否可用。

各项按尺度归一化，避免把“小房间”自动变成惩罚更轻的碎片空间。对厨房/卫生间等的容忍度用显式 room_shape_policy 配置，不猜测中文名称。

## 6. 调度与停止语义

- 正常轮次：只有 completed_episodes % 250 == 0 才精确成图。
- 正常结束或首次用户停止请求：保存最新完整的种子状态，再进行一次精确成图；若同一快照刚生成过则复用。
- 中断发生在回合内部：保存最近完整有效状态，记录实际轮次/步数，不能伪造回合已完成。
- 用户二次强制终止、系统断电无法保证补做成图；通过事先保存的种子快照支持离线补生成。
- 已查明：gui/training_service.py 首次停止写 STOP_REQUEST_FILE，二次停止强制杀进程；当前 train_adaptive_reuse.py 未轮询该文件。CP5 必须一起补齐，不能仅加 finally 就宣称支持停止成图。
- 代理预览和精确成图必须在 WebUI 清晰标识；旧 save_interval（20）不改为 250，二者独立。
